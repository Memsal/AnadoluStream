# AnadoluStream Deposu 🚀

Bu paket, Cloudstream uygulamanız için eksiksiz olarak hazırlanmış bir eklenti deposudur.

## Kurulum Adımları:
1. GitHub üzerinde yeni bir **Public (Açık)** repo oluşturun (Örn: `AnadoluStream`).
2. Bu ZIP dosyasının içindeki tüm dosyaları doğrudan reponuzun ana dizinine yükleyin.
3. GitHub Actions otomatik olarak eklentilerinizi derleyecektir.
4. Derleme tamamlandıktan sonra, Cloudstream uygulamanızı açın:
   * **Ayarlar > Eklentiler > Depo Ekle**
   * Depo Adı: `AnadoluStream`
   * Depo URL'si: `https://raw.githubusercontent.com/Memsal/AnadoluStream/master/repo.json`
